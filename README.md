# Mission Continues. Always. 🚀

A standalone Mission Control landing page for GitHub Pages.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/` — cinematic space visuals and mission gallery images

## Upload to GitHub Pages

1. Open your repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Commit the changes.
5. GitHub Pages should rebuild automatically.

The existing repository and GitHub Pages configuration can remain as they are.
